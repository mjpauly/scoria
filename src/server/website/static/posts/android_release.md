# Scoria For Android

*Jul 16, 2024*

We're pleased to share that Scoria is now available for Android! In fact, it's
been out for a couple of months already. Hopefully the absence of this
announcement wasn't holding you back!

Scoria is available as a direct APK download from [scoria.info](/android). The
app automatically checks for updates at startup, and notifies you if an update
is available.

More updates coming soon!
