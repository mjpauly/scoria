# Android Release Notes

## 1.4.0

*Jul 24, 2024*

- save your favorite places on the map
    - use up to 5 emoji/symbols for icons
    - add tags and notes to each place
    - share places with other Scoria users with `scoria://` links
- timeline and stats
    - see places visited, time spent at each, and time and distance of travel
      between places
- ability to delete datapoints if inaccurate
- configurable automap opacity
- XY plot of colored data vs time
- 12-hour clock support
- option to turn off the basemap

Note: Scoria cannot be downgraded from 1.4 to 1.3, and databases exported from
Scoria 1.4 cannot be imported into Scoria 1.3.
